GENERATOR

开源工具 · Holo Card

整张卡由开源工具 Holo Card 生成与装配：给它一张插画，它负责拆层、抠图、定深度、上 Canvas，产出一张可交互的全息卡。 完整过程记录保留在 job/ 目录（task.json、prompts.json、provenance.json）。

PROMPT

/Holo Card 给我做一张数码宝贝机械暴龙兽的闪卡

就是这一句——一句话进，一张全息卡出。

PROCESS

一张卡的四道工序

01

拆层

用 Holo Card 把一张完整插画拆成角色、场景、UI 框架、结构线四个独立图层，各自重建被遮挡的画面。

02

抠图

角色与 UI 层用独立的 alpha 蒙版抠出，逐张做黑白底对照审查，清掉边缘污染和棋盘格残留。

03

定深度

从角色轮廓生成结构线蒙版，作为各层的前后深度依据——暴龙兽的躯干比背景近，比 UI 文字远。

04

合成

Canvas 上按深度装配四层，指针与姿态驱动视差和光效，得到一张可以拿在手里转的卡。
